## Selected work

**On-premise RAG assistant for regulatory and internal policies · Banking**
Staff used to search long policy documents by hand whenever a rule was unclear. Now they ask a question and get an answer drawn only from those documents, with citations. OCR for scanned PDFs, hybrid search with re-ranking, a locally hosted LLM, and a full audit log. No external API calls.

**General-ledger anomaly detection · Banking**
Auditors cannot read every journal entry. This system scans the full transaction history and flags the unusual ones. Isolation Forest plus a deep autoencoder, with SHAP explanations so every flag comes with a plain-language reason. Runs as a weekly MLOps pipeline with MLflow, data validation and drift monitoring.

**AI features for a dental practice platform · Healthcare, US**
Dentists lose hours to typing notes. I helped build voice-to-text clinical notes drafted by an LLM, hands-free voice charting, a plain-English analytics assistant, and AI-assisted X-ray analysis for clinician review. Built to HIPAA requirements for patient data.

**AI hiring system · HR**
Screening resumes and booking interviews eats days. This system ranks every resume against the job description using several models, shortlists the best fits, books the interview with the right interviewer and emails both sides.

**AI code auditor for GitHub · Developer tooling**
Connects to private repositories, runs static analysis (Bandit, ESLint, PyLint, Trivy) and uses an LLM to write a clear audit report covering quality, security and test coverage.

**LegalSense: offline legal assistant · Legal**
RAG over a penal code with a local LLM. Runs fully offline and cites the section it used.

**Face recognition attendance system · Computer vision**
Marks attendance from a live camera feed. Runs on local hardware at about 92% recognition accuracy.
